# Instruções do projeto

Leia e siga integralmente as instruções em `Claude.md` antes de trabalhar neste repositório.

O gate mínimo obrigatório antes de abrir ou declarar uma MR/PR pronta é:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

Se qualquer etapa falhar, corrija-a antes de prosseguir. As regras detalhadas estão em `Claude.md`.
